# REELS AI COACH

영상 이론을 참고하여 인스타그램 릴스의 기획과 대본 작성을 돕는
웹 기반 AI 챗봇 서비스입니다.

## 프로젝트 목적

릴스 제작 경험이 부족한 사용자가 대화를 통해 주제, 대상 시청자,
영상 길이와 연출 방향을 정리하고 촬영 가능한 대본을 만들도록 돕습니다.

## 대상 사용자

- 릴스 제작을 처음 시작하는 사용자
- 영상의 구성과 대본 작성에 도움이 필요한 크리에이터

## 핵심 사용 시나리오

1. 회원가입 후 로그인합니다.
2. 만들고 싶은 릴스의 주제와 조건을 입력합니다.
3. AI와 대화하며 부족한 제작 조건을 정리합니다.
4. 제작 조건에 맞는 대본을 생성하고 수정합니다.
5. 이전 대화와 결과를 조회합니다.

## 기술 구성

- 백엔드: Python 3.12, FastAPI
- 프론트엔드: HTML, CSS, JavaScript
- 데이터베이스: SQLite
- AI: 서버에서 외부 AI API 호출

## 팀 역할

| 담당자 | 역할 |
| --- | --- |
| 이송하 | 팀장, 서비스 기획, 웹 화면, 통합 관리 |
| 김시현 | 회원가입·로그인, 인증, DB, 대화 기록 |
| 황승재 | AI API 연동, 문맥 유지, 예외 처리, 배포 |

## 개발 현황

현재 공통 프로젝트 기반을 구성하는 단계입니다.
회원가입, 로그인, 채팅, DB 저장, 배포는 이후 담당자별로 구현합니다.

기존 통합 예제 코드는 참고 자료로 활용하며,
이 저장소의 실제 구현·변경·검증 내역을 별도로 기록합니다.

## 협업 방식

- main: 검증된 제출·배포 버전
- develop: 기능 통합
- feature/*: 담당 기능 개발
- 초기 기반 등록 이후 기능 변경은 PR로 병합합니다.
- 팀원별 유의미한 커밋을 10회 이상 기록합니다.
- 개인별 작업 요약은 실제 커밋·PR 이력에 맞춰 작성합니다.

## 민감정보 관리

실제 API 키와 비밀 설정은 환경 변수 또는 .env로 관리합니다.
.env, 가상환경, 로컬 DB는 Git에 올리지 않습니다.
.env.example에는 실제 비밀값을 넣지 않습니다.

## 실행 및 제출 정보

실행 방법, API 명세, DB 구조, DB 확인 방법과
배포 URL은 구현 진행에 따라 추가합니다.
